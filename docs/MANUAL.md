# Manual de usuario

El manual del sistema está escrito en lenguaje simple para quien compra café y vive en un solo archivo:

**[`apps/web/content/manual.md`](../apps/web/content/manual.md)**

Se muestra también dentro del sistema, en el menú **Administración → Ayuda**, a partir de ese mismo archivo (no hay dos copias que se desactualicen).

Para cambiarlo, edita ese archivo. El visor entiende títulos (`#`, `##`, `###`), párrafos, listas con viñetas o numeradas, citas (`>`), línea (`---`), **negrita**, `código` y enlaces; no entiende tablas.

> Regla del proyecto: cuando un cambio modifique lo que ve o hace el usuario, se actualiza el manual en el mismo PR.
